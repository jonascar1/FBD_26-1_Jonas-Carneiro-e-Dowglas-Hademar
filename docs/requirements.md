# Database Requirements:

## 2.1 Business rules:

1. A condominium must have at least 8 apartments and at most 20.
2. Each apartment belongs to exactly one condominium.
3. An apartment can have zero or more residents.
4. A resident can be either an owner or a tenant.
5. Each apartment must have exactly one owner.
6. An apartment may have zero or more dependents.
7. An employee works in only one condominium.
8. Payments must be associated with an apartment.
9. Payments include additional fees if the due date is exceeded.
10. Each apartment that has a tenant must have monthly payments.
11. Each condominium must have a registered address.

## 2.2 requirements:

12. The system must register people.
13. The system must classify people as residents or employees.
14. The system must register residents' dependents.
15. The system must associate residents with apartments.
16. The system must generate payments for apartments.
17. The system must record apartment information.
18. The system must record payments made by each resident.
19. The system must register employees and their information.
20. The system must control employees' working time.
21. The system must manage which apartments belong to each condominium.
22. The system must show which apartments have no residents.
